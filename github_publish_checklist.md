# GitHub Publish Checklist

Use this checklist before publishing the repository.

- [ ] Check notebook runs from top to bottom.
- [ ] Check no private information is included.
- [ ] Check no local machine paths are included.
- [ ] Check no credentials or API keys are included.
- [ ] Check large raw data files are not uploaded.
- [ ] Check processed data files are not uploaded.
- [ ] Check dataset source is mentioned.
- [ ] Check README links work.
- [ ] Check charts display properly.
- [ ] Check findings are supported by notebook outputs.
- [ ] Check limitations are included.
- [ ] Check placeholders such as `[insert finding]` are updated before publishing.
- [ ] Check this repository is positioned as a Python / pandas EDA project, not a duplicate dashboard project.
